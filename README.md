# محسّن الجودة — مشروع أندرويد

## التشغيل
1. ثبّت Android Studio (Ladybug أو أحدث) وافتح مجلد المشروع.
2. انتظر مزامنة Gradle (سيحمّل المكتبات تلقائيًا).
3. وصّل جوالًا (Android 10+) أو شغّل محاكيًا، ثم Run ▶.
4. لإنشاء APK: Build ▸ Build Bundle(s)/APK(s) ▸ Build APK(s).

## المميزات
- خياران فقط: **إضافة صورة** / **إضافة فيديو** (أي دقة أو نسبة أبعاد).
- الدقة: الأصلية، HD 720، Full HD 1080، 2K، 4K — تُطبَّق على الضلع الأقصر فيبقى الإطار كما هو.
- الجودة: قياسية / عالية / قصوى + حدة + لمسة سينمائية (تدرّج لوني) قابلة للتحكم.
- الحجم المتوقع يُحسب حسب المدة والدقة والجودة وترميز HEVC/H.264، مع فحص المساحة الحرة.
- التصدير داخل التطبيق مع شريط تقدّم، ويستمر في الخلفية (خدمة أمامية + إشعار) عند الخروج من التطبيق.
- النتائج تُحفظ في المعرض: Movies/Enhancer و Pictures/Enhancer.

## هيكل الكود
| الملف | الوظيفة |
|---|---|
| `Planner.kt` | الأبعاد النهائية، معدل البت، الحجم المتوقع |
| `ImageEnhancer.kt` | تكبير تدريجي ← حدة ← تدرّج سينمائي ← JPEG |
| `VideoEnhancer.kt` + `SharpenEffect.kt` | Media3 Transformer: تغيير الدقة، حدة GPU، LUT سينمائي، H.265/H.264 |
| `CinematicGrade.kt` | منحنى التباين وألوان الظلال/الإضاءات (مشترك بين الصور والفيديو) |
| `ExportWorker.kt` | WorkManager + Foreground Service + الإشعارات + الحفظ في المعرض |
| `ui/MainScreen.kt` | الواجهة (Compose، عربي RTL) |

## ملاحظات مهمة
- التحسين يعتمد على **تكبير + حدة + تدرّج لوني**، وليس ذكاءً اصطناعيًا يولّد تفاصيل جديدة. للحصول على ذلك لاحقًا يمكن إضافة نموذج Real-ESRGAN عبر TFLite/NCNN.
- لم يُجرَّب البناء داخل بيئة الإنشاء. إن ظهر خطأ تجميع في كود Media3 (`VideoEnhancer.kt` / `SharpenEffect.kt`) فغالبًا سببه اختلاف بسيط في إصدار المكتبة؛ الإصدار المثبّت هو 1.5.1 في `app/build.gradle.kts`.
- على بعض الأجهزة قد لا يدعم المرمّز العتادي 4K أو HEVC؛ التطبيق يفعّل الرجوع التلقائي لإعداد مدعوم.

## الحصول على APK بدون Android Studio
1. أنشئ مستودعًا جديدًا في GitHub وارفع محتويات هذا المجلد (بما فيها `.github`).
2. افتح تبويب **Actions** ← **Build APK** ← انتظر نحو 5 دقائق.
3. من أسفل صفحة التشغيل نزّل **QualityEnhancer-apk** (ملف ZIP فيه app-debug.apk) وثبّته على الجوال.
